# Solar System Simulation 🌞🪐

**Solar System Simulation** is an interactive 3D simulation of a solar system using **Three.js**, featuring planets, asteroids, and a dynamic video background. Planets orbit the Sun with realistic speeds and trajectories based on their actual parameters (eccentricity, inclination, etc.). The simulation also includes an asteroid belt and a spherical asteroid cloud, with interactive features for users to explore.

---

## 📌 Features
- Realistic planetary textures and elliptical orbits  
- Asteroid belt and spherical asteroid cloud  
- Animated spherical video background  
- Interactive controls:  
  - Hover over a planet to pause its rotation  
  - Click on a planet to open a detailed information page  
- Floating labels displaying planet names  

---

## 🛠 Requirements
- Three.js (CDN included in HTML or install via npm)  
- A local server to serve the files (e.g., **Live Server** in VSCode)  
- Modern web browser with WebGL support  

---

## ⚙️ Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/YIJ18/ThreeJS-SolarSystem.git
   cd ThreeJS-SolarSystem
   ```
2. Open the project in VSCode or your preferred IDE.  
3. Start a local server to serve the files:  
   - Using **Live Server** in VSCode, right-click `index.html` → `Open with Live Server`.  
4. Open the URL provided by the server in your browser to run the simulation.  

---

## 🚀 Usage
- Move your cursor over a planet to pause its rotation.  
- Click on a planet to access a page with detailed information.  
- Explore the asteroid belt and spherical asteroid cloud around the Sun.
